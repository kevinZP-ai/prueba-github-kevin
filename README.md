# Prueba de GitHub

## Lo que aprendí en el curso

- Crear repositorios y organizar los archivos del proyecto.
- Trabajar con ramas y pull requests.
- Usar issues para registrar y cerrar tareas.

Para consultar la documentación oficial usé [Microsoft Learn](https://learn.microsoft.com).

Algunos comandos básicos:

```bash
git init
git add .
git commit -m "Primer commit"
```
